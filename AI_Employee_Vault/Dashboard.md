# AI Employee Dashboard

## Overview
This dashboard provides a real-time overview of the AI Employee's activities, vault status, and pending actions.

## Vault Structure

### Communication Vaults
- **Inbox**: Incoming emails, messages, and notifications awaiting processing
- **Needs_Action**: Items requiring immediate attention or action
- **Done**: Completed tasks and archived communications
- **Logs**: System logs, audit trails, and historical records

### Planning Vaults
- **Plans**: Active and historical plan files generated by the AI
- **Pending_Approval**: Actions awaiting human approval before execution
- **Approved**: Actions that have been approved and ready for execution
- **Rejected**: Actions that were rejected by human reviewers
